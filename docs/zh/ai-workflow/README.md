方法，两篇笔记。每个平台模块都带着自己的 AI-ramp；这两篇是它们背后共享的哲学，也是让 AI 不至于
悄悄把事情搞砸的那一部分。

| 笔记 | 它是什么 | 什么时候读 |
| --- | --- | --- |
| [`how-i-use-ai-to-learn-and-operate.md`](how-i-use-ai-to-learn-and-operate.md) | **那条 ramp。** 到一个新地方：用 AI 去测绘一个你从没碰过的平台的那几条编号规则，以及让那张图保持诚实的护栏 | 你正要上手某样东西，或者想知道各平台 AI-ramp 所假设的那些规则 |
| [`ai-in-the-day-job.md`](ai-in-the-day-job.md) | **稳态。** 一个普通的星期二 —— 分诊 → 变更 → 事故 → 复盘 → 清扫 —— 每一步说清交给 AI 什么、在哪里把它拿回来 | 你已经在运维那个东西，想要的是分工而不是 ramp |

第一次按这个顺序读；之后第二篇是你会反复回来的那一篇。[操作模型](../00-the-operating-model.md)
是两篇都假设的东西，而 [`WHY.md`](../WHY.md) 是这套纪律在 AI 时代为什么更要紧而不是更不要紧。
