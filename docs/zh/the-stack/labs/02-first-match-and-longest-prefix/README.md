# Lab 02 —— 两个文件，两种查找纪律，而纸面上没有一处说明是哪一种

> **输入：** 无 · **输出：** 每个文件产出的那些判定，打乱过的和没打乱的 · **风险：** 无 ——
> 不用网络、不用云、不用凭据 · **root：** 不需要

**目标：** 把[第 02 章](../../02-network.md)在两个不同小节里各说了一遍、而几乎没有人把它们当成
**同一个**想法来握住的那件事，变得无可辩驳 —— 一条网络路径是由两种查找纪律决定的，它们在纸面上
看起来一模一样，而它们不是。

```
a routing table   resolves by LONGEST PREFIX  — order-independent
a firewall ruleset resolves by FIRST MATCH     — order-dependent
```

**你会练到：** 在读一个文件*之前*先问它用的是哪种纪律 —— 而那正是两个文件都不回答的那一个问题。

## 这个 lab 为什么是纯本地的

这个故障在成为一个网络故障之前，先是一个*推理*故障。两个文件都是一串每行带一个地址的有序列表、
都显示在一块按顺序呈现它们的屏幕上，而它们之间的差别完全住在那个解析器里。这完全可以用一个模型
表达出来 —— 两个类，一个 `max(prefixlen)` 和一个 `hits[0]` —— 而把它建成模型，正是让这个对比在
一屏之内可见、而不是跨着相隔一年的两次事故才可见的原因。

不用网络、不用云、不用凭据、不用 `pip install`。Python 标准库，CI 也跑得了。

## 跑它

```bash
python3 the-stack/labs/02-first-match-and-longest-prefix/lookup_order_drill.py
```

exit code `0` 表示关于这个教训的每一条断言都成立。

## 你会看到什么

1. **两个文件，并排打印出来。** 形状一样。哪一个都没有声明它的解析器。

2. **各打乱二十次。** 路由表给出的每一个判定都一模一样；规则集二十次打乱里有十一次改变了某个
   判定。那就是全部的差别，被测量出来了。

3. **镜像错误，第一个方向："把那条路由挪上去，让它优先。"** 一张工单说某台主机走错了方向，那一行
   被提到了最上面，然后**什么都没变** —— 而运维者把这读成了*路由不是问题所在*。它就是问题所在；
   解法是一个不同的前缀或者下一跳，而那一行坐在哪儿从来就不会有影响。

4. **镜像错误，第二个方向："在最上面加一条宽的 allow 把它放行掉。"** 一条
   `allow 10.20.0.0/16 any` 让它下面**三条**规则变成惰性的，包括一条刻意为之的隔离 deny。那套规则
   仍然*包含*那条 deny —— 它的截图是如实的 —— 而控制台、diff 和访问复审里没有任何东西会报告
   *从不匹配*。

5. **值得带走的那个不对称。** 路由表最后一行的一个 `/32` 打得过第一行的 `/0`。规则集最后一行的一个
   `/32` 输给第一行的 `/16`。**同一条具体的行在一个文件里赢、在另一个文件里输**，而那句话就是这个
   lab。

## 验证（别光信这个脚本说的）

一个不会失败的自我验证器毫无价值。这里有两条彼此独立的破坏路径，而每一条都把那个*错误的模型*实现
出来，好让你看清它本来会预测什么：

```bash
python3 lookup_order_drill.py --sabotage routes-first-match    # exit 1
python3 lookup_order_drill.py --sabotage rules-longest-prefix  # exit 1
```

如果一张按 first-match 解析的路由表还能通过，那 longest-prefix 本来就什么都没决定；如果一套按
longest-prefix 解析的规则集还能通过，那顺序本来就什么都没决定。两条各自打断三条断言，而第三条在
两边是同一条：具体性在两个文件里不再表现得不一样 —— 而那恰恰就是这个演练存在着要点名的那份混淆。

想再往前一步，在那条宽 allow *下面*再加第四条规则然后重跑：被遮蔽的数目变成四，而别的输出一动
不动。规则集变长了而估算面没有变化 —— 一个规则文件就是这样长到四十行、其中只有九行能触发的。

## 重点

**在你读任何一个文件之前，先问它用的是哪种纪律。**

三件要带走的事：

- **重排一张路由表是一次空操作，而它读起来像一个被排除掉的假说。** 危险的不是那浪费掉的一分钟；
  是那一分钟末尾那个错误的结论。
- **最上面一条宽规则是一次安静的批量禁用。** 它下面那些规则仍然存在、仍然复审通过、而且永远不
  触发。去问一套规则集它有哪些规则*能够*匹配，而不是有哪些规则在那儿。
- **具体性在一个文件里是决胜项，在另一个文件里毫不相干。** 把错误的直觉带过去，会产出两个互为镜像
  的失败，而它们哪一个都不会自报家门。
