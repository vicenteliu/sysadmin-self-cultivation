> [`skills-maps/`](../skills-maps/README.md) 回答*我会什么*。这里回答*他们怎么查* ——
> 同样的材料、同样的小节，从桌子另一侧看。

一张技能图是一份你去打勾的能力清单。一次面试是某个人在判定那个勾是不是真的。这两组文件一对一
配对：这里的每一个小节都和那边的某个小节同名，所以一个问题总是通回它所考的那项能力，而一项能力
也总是通向它被怎么探。

## 条目格式

四个部分，而**第四个的形状会随这一节的标记而变。**

```
### "那个问题，按它实际被问出来的样子"                     🔨 或 🧭
**Probes：** 被考的那份判断 —— 绝不是被回忆的那个事实。
**Answer：** 一个工作实例（🔨），或者那份诚实 ramp 的表述（🧭）。
**Prove it：** 一个可跑的 lab 或工具，如果存在的话。
```

**在 `🔨` 之下，那个答案是一个工作实例** —— 真的发生过、并且被匿名讲述的某件事。它不是一段拿来背
的稿子。它是**那个标记的证据**：一个背后什么都没有的 `🔨`，是一次藏在任何审计所能及之处再下一层
的过度声称，而那正是
[ADR-0004](../../../adr/0004-interview-answers-are-evidence-for-a-marker.md)
的全部论点。

**在 `🧭` 之下，那个答案是那条诚实的 ramp** —— 什么被测绘并验证过、什么可迁移，以及那条边界坐在
哪。这里没有一个标准答案可给，而且也不需要有。
[`honesty-audit`](../../../../.claude/skills/honesty-audit/SKILL.md) 论证过：一条被平白说出的
ramp 读起来像判断，而不像一个缺口，而那份表述本身就是答案。说*"我没有在生产里跑过这个，这是我
确实验证过的东西，这是可迁移的部分"*，是一个比一次流利的虚张更强的回答，而且它是唯一一个熬得过
第二个问题的。

## 匿名化在这里不是可选项

一个问题加上它所探的东西是通用的。**一个答案是具体的，而具体性会定位到一个雇主。** 这些页面上的
每一个工作实例都遵循 ADR-0004 里那门纪律：

- **规模和形状，绝不是地点或当事方。** 一片区域级的 vCenter 估算面、十万个节点、五年的 ITSM 任期
  —— 这些都留得下来。地区名、公司名和能对齐的日期留不下来。
- **不留可重建的时间线。** 一次故障是一串决定，不是一个带时长的日期。
- **那个测试是组合式的。** 任何单条细节都可能无害，而整个集合却是可识别的。要问的不是
  *"这条敏感吗"*，而是*"在这一页上已有的一切之下，这条会不会把范围缩小"*。

## 这不是什么

**不是一份用来背的题库。** 一个背下来的答案会在追问上垮掉，而追问才是真正决定一次面试的那个问题。
这里写下来的是**材料** —— 那个实例和那份表述 —— 而在压力下把它回忆出来是另一项技能。
[`interview-drill`](../../../../.claude/skills/interview-drill/SKILL.md) 是干这件事的那条循环：
它提问、追问，并检查那个答案是留在了证据上、还是飘进了那个流利的版本里。

**不是那些章节的替代品。** 和一个 [build-out](../../build-out/README.md) 步骤一样，这里一个开始
解释某样东西怎么工作的条目就已经失败了 —— 那份解释已经存在，而第二份拷贝是第二样要去维持为真的
东西。
