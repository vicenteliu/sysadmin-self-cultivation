# Lab —— "谁能看见这个？"不是靠读那些权限来回答的

> 🌐 **语言：** [English（默认）](../../../../../cross-cutting/labs/permission-sprawl/README.md) · **中文**
>
> ⚠️ 本项目**默认语言为英文**，`cross-cutting/labs/permission-sprawl/README.md` 是"事实来源"。本页中文是多语言支持的一部分，可能略滞后于英文版；两者不一致时以英文为准。

---

**目标：** 把审计师真正的那个问题变得摸得着。不是*它锁紧了吗* —— 而是**谁能看见这个，以及你怎么
知道？** 后半句才是那个会失败的，而且它是安静地失败的，在一片从分享对话框看过去一切正常的估算面里。

**你会练到：** [build-out 第 07 步](../../../build-out/07-files-and-collaboration.md)所坚持的那门
纪律 —— 权限用组来表达、分享链接拴上绳子，以及一次真的检查了它声称在检查的那样东西的复审。

两片估算面，同一周建起来的，同样的文档，同样的一百个人。一片只通过组来授予访问。另一片说了四次
*就这一次*，并且把链接分享开着。看得见的差别是多出四个名字。实际的差别是九十三个人。

## 这个 lab 为什么是纯本地的

权限蔓延是一个*结构性*失败，不是一个厂商问题。它在每一套办公套件里都以同样的方式发生，因为每一套
都有同样那两条授予路径 —— 一张访问控制列表和一条分享链接 —— 而只有第一条是人们说"权限"时指的那个。
这完全可以用一个模型表达出来：主体、嵌套的组、带或不带记录理由的授予，以及带范围和过期期限的链接。

不用租户、不用套件、不用凭据、不用 `pip install`。Python 标准库，CI 也跑得了。

## 跑它

```bash
python3 cross-cutting/labs/permission-sprawl/sprawl_drill.py
```

exit code `0` 表示关于这个教训的每一条断言都成立。

## 你会看到什么

1. **一个看得见的差别。** 四次单独授予。它读起来像是一点小小的不整洁，而这恰恰是没人把它升级上去
   的原因。
2. **那张 ACL 少算了 —— 两边都少算。** 那片干净的估算面有一个它的 ACL 没有点名的读者（一条带范围
   的审计师链接，是刻意的）。那片蔓延的有 **93** 个，因为"任何拿到链接的人，永不过期"意味着整个
   公司。
3. **那次访问复审返回"干净"。** 走一遍组成员关系会检查三个人。它径直跨过了那四次单独授予 ——
   他们不是组成员 —— 而且它根本看不见那些链接读者。这不是一个错误的答案。它是对另一个问题的一个
   正确答案。
4. **"这个人为什么有访问权？"** 在那片只用组的估算面里，每一次授予都用一个角色来回答，所以那个
   理由活得比授予它的那个人还久。在那片蔓延的估算面里，有四次授予没有任何被记录的理由，而且一个
   都重建不出来。
5. **吊销才是那个测试。** 把一个人从那个组里移除。那片干净的估算面处处都吊销掉了。那片蔓延的什么
   都没吊销 —— 那条开着的链接照样放他进来，而任何一个去读那个组的人都不会知道。

## 验证（别光信这个脚本说的）

```bash
python3 .../sprawl_drill.py --break-it   # exit 1
```

`--break-it` 会让那次审计忽略分享链接 —— **也就是访问复审实际上被执行的方式**。每一个隐藏的读者都
从结果里消失了，那两片估算面开始看起来差不多，而这个演练带着被点名的那些挂掉的断言 `1` 退出。

那是这个教训最锋利的形态：那次破坏不是一个奇异的故障，它就是行业标准做法。

想再往前一步，把那条开放链接的 `expired` 设成 `True`，看着 93 个读者消失 —— 一个字段、一条链接，
比任何数量的组卫生都更值钱。

## 重点

**一个权限模型，只有在吊销真的生效时才算是一个模型。** 如果把一个人从组里移除并没有移除他的访问权，
那你手里的就不是一个模型 —— 而是一份决定的历史，而倒着去读它是考古。

三件要带走的事：

- **有两条授予路径。** 在你看得见的那条上做到完美纪律，如果另一条开着，那什么都换不来。
- **一次走组的复审，对着错的那个集合是干净的。** 要问一次复审*检查了*什么，而不是它*得出了*什么。
- **单独授予会丢掉它的理由。** 那一下点击花一秒；它制造的那个回答不了的问题，会和那份文档活得
  一样久。

没有。这个演练把所有东西都放在内存里，不写任何文件。
