# Lab —— "VPN 连不上"是四个不同的问题

> 🌐 **语言：** [English（默认）](../../../../../cross-cutting/labs/remote-access-four-causes/README.md) · **中文**
>
> ⚠️ 本项目**默认语言为英文**，`cross-cutting/labs/remote-access-four-causes/README.md` 是"事实来源"。本页中文是多语言支持的一部分，可能略滞后于英文版；两者不一致时以英文为准。

---

**目标：** 把远程访问支持里代价最高的那个习惯变得摸得着 ——
**四个互不相关的成因产出一份字节级一模一样的用户报告**，所以从症状去诊断，就是多绕了几步的猜。
你会看着那些反射式检查（"重启一下"、"隧道起来了吗？"）什么都排除不掉，看着两个成因互相假扮，然后
看着一组有顺序的检查 —— 每一个都凭它*排除了*什么被挑中 —— 每次都到得了，而且最坏情况有界。

**你会练到：** [`toolbox/linux-triage`](../../../toolbox/linux-triage/) 所建于其上、而
[build-out 第 10 步](../../../build-out/10-remote-access.md)点名为它的头号工单的那门纪律 ——
*每一个检查都必须排除掉某样东西*。

那四个，直接来自那一步：

1. 网关上一张过期的证书
2. 那个身份提供方够不到
3. 一个 captive portal 在拦截（酒店、咖啡馆、机场）
4. 那条隧道装了一条更具体的路由，而它不承载认证流量

## 这个 lab 为什么是纯本地的

这四个里的每一个，在成为一个网络故障之前，都先是一个*推理*故障。让这张工单变贵的不是那些包难看见
—— 而是那个症状在四个世界里都一模一样，而那些显而易见的检查什么都没收窄。这完全可以用一个模型表达
出来：四个世界状态、一组检查，以及每一个检查留下的那个可能性集合。

不用 VPN、不用网关、不用租户、不用凭据、不用 `pip install`。Python 标准库，CI 也跑得了。

## 跑它

```bash
python3 cross-cutting/labs/remote-access-four-causes/four_causes_drill.py
```

exit code `0` 表示关于这个教训的每一条断言都成立。

## 你会看到什么

1. **四次事故，一份报告。** 四个都打印出同一句话。那条断言是：不同症状构成的那个集合，大小为一。
2. **那些反射式检查什么都排除不掉。** "重启客户端"和"隧道连上了吗？"在每一个世界里，都让全部四个
   成因保持可能。它们感觉像进展，是因为它们产出了一个*结果*，不是因为它们移除了一个可能性。
3. **那次假扮。** "我够得到那个身份提供方吗？"对一次真正的身份故障和一个 captive portal 返回同一个
   答案。恰好只有一个观察把它们分开：DNS 是不是在*诚实地*应答 —— 一个 portal 什么都应答，而且用它
   自己来应答。
4. **那个阶段陷阱。** 成因 #4 是在隧道报告"已连接"*之后*才失败的。它是唯一一个"起来了吗？"回答
   "是"的世界，这意味着那个反射式检查不只是浪费了一步 —— 它还把你指向了故障的反方向。
5. **猜对上排除**，在全部四个世界上跑一遍。排除法解决 4/4，最坏情况 3 个检查。那个习惯顺序解决
   2/4，而且在还剩两个成因站着的时候就把检查用光了。

## 验证（别光信这个脚本说的）

一个不会失败的自我验证器毫无价值。去破坏它：

```bash
python3 .../four_causes_drill.py --break-it   # exit 1
```

这会把那个 DNS 诚实性检查换成一个什么都排除不掉的 —— 也就是和从来不问那个问题一样的错误。排除法
立刻掉到 2/4，因为那个 portal 和那次真实故障现在分不开了，而这个演练会带着被点名的那条挂掉的断言
`1` 退出。

想再往前一步，编辑 `ELIMINATION_ORDER`，把那个证书检查挪到最后：那些答案仍然是对的，而代价上升了
—— 这是同一课更安静的那个版本 —— 顺序不是装饰。

## 重点

**一项检查凭它排除了什么赢得位置，不是凭它报告了什么。**

服务台会见到这张工单，比任何别的都多，而且永远如此。按症状处理，它是四次开局动作相同的不同的猜。
按排除法处理，最坏情况被成因的数目框住 —— 而那个达成它的顺序才是交付物，不是那些单条命令。

那两个陷阱是值得从这里带走的部分：

- **两个成因可以对同一个合理的问题给出同一个答案。** 找到那个把它们分开的问题，才是真正的技能。
- **一个在"已连接"之后才失败的成因，能打败每一个存活性检查。** 起来了不等于是对的。
