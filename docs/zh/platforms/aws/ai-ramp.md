# AWS —— 那条 AI 辅助 ramp

> 怎么在几天而不是几个月里在 AWS 上走到*胜任* —— 用 AI 当副驾，并且让它保持诚实。这套方法可以
> 泛化到任何平台。

学一朵云的老办法，是把一门认证课从头磨到尾，然后指望相关的那两成留了下来。问题从来不是那些材料
—— 而是你当时还不知道对你面前这份工作来说要紧的是*哪*两成，所以你排不出优先级。那个"未知的未知"
阶段，正是 AI 所压掉的东西。但 AI 也会发明服务名、记错 API 参数，并写出自信的、说得通的、
*错的* IAM policy。所以这套方法是两门纪律被扣在一起：**AI 提供速度，判断提供真相。**

## 那条循环

对任何一个新领域（比如 VPC 网络）：

1. **锚定到你已经知道的东西上。** 不要问"教我 VPC"。要问 *"我已经理解 Linux、TCP/IP、subnet、
   路由和本地防火墙 —— 把这些映射到一个 AWS VPC 上。什么是一样的、什么被改了名，以及什么是真的
   不同？"* 你拿到的是一次翻译，不是一场讲座，而且它几分钟就落地。
2. **拿到那 80/20。** *"在 AWS 网络的一切里，一个管理员每天用的是哪两成，而我可以安全地推迟哪些？"*
   现在你能排优先级了。
3. **生成那个产物。** *"写一条最小权限 IAM policy，让这个 role 恰好只读一个 S3 桶"*，或者
   *"给一个跨两个 AZ、一个公有一个私有 subnet 加一个 NAT 的 VPC 写 Terraform"*。几秒钟出第一稿。
4. **核实 —— 这是那个不容商量的步骤。** 对着**官方 AWS 文档**交叉核对每一个服务名、每一个参数、
   每一条权限。AI 的故障模式是*自信地错着*：一个不存在的 policy action、一个已经变了的默认值、
   一个它幻觉出来的资源参数。假定那份初稿九成是对的，然后去猎那一成。
5. **在一个用完就扔的账号里跑它。** 一个带**硬预算告警**的沙箱/开发账号。现实是最后那位评审者 ——
   一份 `terraform apply` 得下去、并且能被干净 `destroy` 掉的栈，比任何解释都值钱。
6. **让 AI 反过来评审你的成果。** *"这是我的 Terraform / 我的 security group —— 我漏掉了什么安全
   或成本风险？"* 它是一双很强的第二只眼睛，只要**你**仍然是那个做决定的人。

## 那些真能挣到饭钱的提示词模式

- **翻译者：** *"在我已经懂 Linux/网络/IAM 概念的前提下解释 X —— 只讲 AWS 特有的那部分差量。"*
  （跳过那份新手税。）
- **80/20：** *"关于 X，我必须理解的最小集合是什么才算能干活，而什么可以安全地推迟？"*
- **陷阱猎手：** *"在 X 上最常坏掉或者最常让人意外的三件事是什么，我怎么避开它们？"*
- **最小权限生成器：** *"写出恰好只做这件事、不多做任何事的那条最紧的 IAM policy。"*
  （然后你自己再手动收紧一层。）
- **评审者：** *"从安全、成本和可靠性上评审这份 IaC / policy / 架构。"*
- **橡皮鸭：** 把一条报错、一段 `aws` CLI 输出、一次被拒绝的请求贴进去 ——
  *"带我走一遍这是什么意思，以及我会怎么调它。"*

## AI 会烧到你的地方（所以这些验得最狠）

- **IAM policy 的 action 与 condition** —— 它会发明看起来很像的 action 字符串。
- **变过的服务默认值** —— 例如 S3 的公开访问和加密默认值这些年变过；AI 会把不同时代混起来。
- **Terraform/CloudFormation 里的资源参数** —— 错的属性名、已废弃的属性名。
- **成本** —— 它会很乐意建议一套既正确又昂贵的架构。
- **任何关乎安全的东西** —— 加密、密钥策略、网络暴露面。绝不要凭信任发布这些；核实并测试。

## 为什么这是一项**系统管理员的**技能，而不是一条绕过它的捷径

一个 AI 能在几秒钟里生成一个 VPC。它没法告诉你那个请求之所以被拒绝，是因为那个 NACL 是无状态的
而你只开了入站那一侧。它感觉不到一个 security group 离把一个数据库暴露到互联网上只差一行。它
拥有不了凌晨三点那次故障。那份判断 —— 最小权限的直觉、"这个为什么够不到那个"、读懂那次失败、
在成本和可靠性之间权衡 —— 才是那门手艺。AI 只是把"**拥有**那份判断"和"把它**施加**到一个你还没
碰过的平台上"之间那几个月的死记硬背移走了。

那就是这整个项目的论点，落在一个平台上：**心智模型是那份资产；AI 是那个加速剂；核实是那门让它
变安全的纪律。**
