# 这个站点是压在材料之上的一个视图，不是第七条轴

> 🌐 **语言：** [English（默认）](../../../../docs/adr/0005-the-site-is-a-view-not-a-seventh-axis.md) · **中文**
>
> ⚠️ 本项目**默认语言为英文**，`docs/adr/0005-the-site-is-a-view-not-a-seventh-axis.md` 是"事实来源"。本页中文是多语言支持的一部分，可能略滞后于英文版；两者不一致时以英文为准。

---

这个仓库现在在 [`site/`](../../site/README.md) 下带一个浏览器 —— 导航、全文搜索、一个语言
切换器、渲染出来的图。它是这里第一样既不是文档也不是工具的东西，而它引出的问题是：它被允许变成
什么。作者看着长起来的每一个文档站点，最后都长出了自己的页面：一份不在仓库里的"快速开始"、一个
把 README 换个说法的落地页、一份只存在于站点上的教程。

## 决定

**这个站点渲染材料，并且不添加任何材料。** 读者看到的每一个词，要么在一个 GitHub 也会渲染的
Markdown 文件里，要么就是 UI 外壳 —— 一个按钮、一个分面名、一条空状态提示。这个站点没有哪一页
不是仓库里的一个文件，而仓库里也没有哪个文件是被这个站点改进过的。

这是把 [ADR-0001](0001-the-build-out-is-a-route-not-a-seventh-axis.md) 那个测试施加到第二个
候选者身上：*它教不教一个新页面？* `build-out/` 不教，于是被归为一条路线。这个站点不教，
于是被归为一个视图。

## 考虑过的选项

- **一个带自己内容层的文档站点** —— 一个手写的首页、各版块的落地页、一次导览。否决。它和
  ADR-0001 所否决的是同一个失败，只是在一个更难看出来的介质里：一个站点页面在这棵树里没有路径，
  所以没有任何东西让它出现在 `docs/index.json` 里、没有任何东西让它镜像到 `docs/zh/`、也没有任何
  东西在它变陈旧时抓住它。材料会分叉，而那个分叉会是人们真正在读的那份拷贝。

- **干脆没有站点；GitHub 就是那个阅读器。** 确实诱人，而且这也是这个仓库在此之前一辈子在做的
  事。因为一个 GitHub 修不了的理由而被否决：二十万字，没有全文搜索。这个站点做的其他一切 ——
  分面、语言切换、一张带主题的图 —— 都是便利。搜索不是。

## 后果

- **首页是生成的，不是写的。** 它的那些计数、它的轴卡片和它的路线入口，都是在加载时从
  `docs/index.json` 算出来的。当一条轴多了一份文档，首页会自己说出来，不用任何人去编辑 ——
  而且它说不出任何那个索引不知道的东西。
- **`build-out/` 拿到一个视图，不是一张卡片。** 这个站点把那十六个路线步骤渲染成一条线性轨道，
  刻意放在轴列表之外，因为把它画成第七张卡片，就是在像素里重犯 ADR-0001 那个错误。
- **一个"只在站点上的功能"请求是一个内容问题。** 如果一位读者需要某样站点显示不了的东西，那个
  修复是一个 Markdown 文件 —— 然后站点会显示它、GitHub 会显示它、索引会找到它，而中文镜像可以
  跟上。这个 viewer 永远不是一个事实第一次出现的地方。
- **这个站点可以被删掉而不损失任何东西。** 那就是那个测试。如果删掉 `site/` 会让这个仓库损失一个
  事实，那条边界就已经被越过了。
