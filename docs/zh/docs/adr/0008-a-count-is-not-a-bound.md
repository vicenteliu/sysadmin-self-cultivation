# 一个计数不是一条界限

> 🌐 **语言：** [English（默认）](../../../../docs/adr/0008-a-count-is-not-a-bound.md) · **中文**
>
> ⚠️ 本项目**默认语言为英文**，`docs/adr/0008-a-count-is-not-a-bound.md` 是"事实来源"。本页中文是多语言支持的一部分，可能略滞后于英文版；两者不一致时以英文为准。

---

[ADR-0007](0007-a-figures-medium-is-decided-by-what-renders-it.md) 决定 mermaid 是默认项，
而一张带品牌的 hero 图是那个有界的例外。那个决定仍然成立。它的两句话不成立：

> **hero 图是那个例外，而它是有界的。** 存在四张……
>
> **第五张 hero 需要一个论证，不是一个时机。** 那条界限就是让这个例外不至于变成规则的东西。

一共有七张。`site-network`、`vsphere-500vm` 和 `esxi-host-network` 是在三次分开的提交里被加上的，
而**第五张本该需要的那个论证，对它们中的任何一张都没有被做出。** 每一张都被对着它上面那条规则
仔细推敲过 —— 这张图携带了散文没有携带的东西吗 —— 而一次都没有对着那条界限推敲过，尽管它一直坐
在一份决策记录里。

什么都没抓住它。`build-diagrams.py --check` 数源码和产物，并且会很乐意报告一个七、一个二十一，
因为一个脚本没法知道七比一份 ADR 里的一句话所说的应该是多少更多。

## 决定

**那条界限是一条判据，不是一个计数。** 当**布局本身携带含义**时才去够一张 hero 图 —— 一个焦点
元素、一层刻意的层次、一种自动布局引擎会摧毁的空间关系。当只有拓扑要紧时就去够 mermaid，而那是
绝大多数时候。

那个测试接纳全部七张并解释了为什么，而那个计数从来没做到：

| 图 | 它的布局携带什么 |
| --- | --- |
| `repo-map` | 包含关系 —— 六个视图在一个本体**里面**，那条路线横跨同样的宽度 |
| `stack-layers` | 顺序，以及七个同侪之中一个焦点层 |
| `seven-surfaces` | 一根高高的中间列，两侧是用它的那套方法 |
| `build-out-route` | 比例 —— 各阶段按它各装多少步来分配间距 |
| `site-network` | 一条边界 —— 防火墙是哪个网段的网关 |
| `vsphere-500vm` | 四个层，每一层是一种不同的东西 |
| `esxi-host-network` | 一次绑定 —— 一个 `vmk` 被钉到一条上联上，而一份清单展示不出来 |

它同样仍然拒绝一些东西。一个目录索引、一条三节点的链、一张被重画成方框的表：这些都没有一个有含义
的布局，而 mermaid 或者散文会接手它们。

## 考虑过的选项

- **保留那个计数并把它提到七。** 因为这份 ADR 存在的那个理由而被否决：那个数字在下一张图上又会
  是错的，而那个看不见 ADR 里一个计数的检查仍然看不见它。一条没人能执行的界限是装饰。

- **保留那个计数并删掉那三张图。** 按证据被否决。每一张都被单独论证过，而每一个论证都站得住；
  错的是那条界限，不是那些图。为了保住一句话而删掉好的工作 —— 是错误的修复。

- **在 `--check` 里执行那个计数。** 作为错误形状的执行而被否决 —— 它会在某人加上一张理应存在的图
  的那一天失败，而那是一个训练人们去绕过它的检查。同样的推理，从 `docs/build-index.py` 的摘要闸门
  里移走了四条过于积极的规则。

## 后果

- **这一类失败没有自动化守卫，而这份 ADR 也不发明一个。** 一条只住在散文里的规则，只由某个人重新
  去读那段散文来执行。现在**确实**被守住的东西更窄、也更机械：`build-diagrams.py --check` 长出了
  一个文字溢出检查，因为在有人仔细看之前，已经有四张图带着框外的文字发布了出去。
- **一张图必须对着它将要坐进去的那段散文、以及对着它附近的那些图被核对。** 两种失败在这里都发生
  了：一张图画了一个 `/16`，而它即将坐在其上方的那张表一直指定的是一个 `/22`；另一张断言了"第二
  个故障域"，而它上面没有任何东西演示了这一点。这两个对这个仓库里的任何 `--check` 都是不可见的，
  而两个现在都被写进了
  [`diagram-module`](../../../../.claude/skills/diagram-module/SKILL.md)，作为步骤而不是作为希望。
- **诚实的记录是：一份决策记录被违反了三次，才有人把它读回来。** 把规则写下来是不够的。那件事对
  `docs/adr/` 里其他每一条规则也一样值得知道。
