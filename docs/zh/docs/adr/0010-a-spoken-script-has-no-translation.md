# 一份口播稿没有译本

> 🌐 **语言：** [English（默认）](../../../../docs/adr/0010-a-spoken-script-has-no-translation.md) · **中文**
>
> ⚠️ 本项目**默认语言为英文**，`docs/adr/0010-a-spoken-script-has-no-translation.md` 是"事实来源"。本页中文是多语言支持的一部分，可能略滞后于英文版；两者不一致时以英文为准。

---

这个仓库关于语言有一条规则，而它对目前为止的每一份文档都成立：**英文是事实来源，`docs/zh/` 是一份
镜像，而在它们不一致的地方英文赢。** `docs/build-index.py` 实现了它 —— `docs/zh/` 下面的一切在
第一遍被跳过，然后作为 `derived: true` 带着一个 `mirrors:` 指针被重新挂上 —— 而
`site/js/nav.js` 读那份关系，好在界面是中文时优先用那份镜像。

一篇[走读](0009-the-walkthrough-ships-its-script-not-its-audio.md)套不进去。一份镜像是一次翻译，
而翻译保住事实、摧毁语流 —— 对一份全部价值就在于它念出来是什么样的文档来说，这恰好是反的。一份
从英文渲染出来的中文稿用英文呼吸，而一份从中文渲染出来的英文稿用中文呼吸。两份都正确，而两份都
没法听。

## 决定

**每一集两份稿子，谁也不是从谁派生出来的，两份都绑在同一组 sources 上。**

`walkthrough/01-….en.md` 和 `walkthrough/01-….zh.md` 并排坐在这条路线自己的目录里。每一份
**对它自己的语流**是正本。两份都不带 `derived: true`；两份都不用 `mirrors:` 指向对方。

**"英文赢"被收窄到它一直以来实际所关乎的东西 —— 那些事实。** 两份稿子声明同样的 `sources:`，
而那些源是英文 Markdown。两份稿子之间的一次不一致，不是靠偏向其中一份稿子来裁决的；它是靠去读
两份都要对之负责的那个源来裁决的。那是一句比旧规则更小的声称，也是更真的一句。

**中文稿不住在 `docs/zh/` 下面。** 位置是一句关于关系的声称，而那个目录说的是*译本* ——
对 `build-index.py` 是这样说的（它会把这个文件盖上 `derived`），对一个读这棵树的人也是这样说的。
把一份正本文档放在那儿、然后再写一条例外去把它取消掉，比不发出那个信号更糟。

## 考虑过的选项

- **遵循已有规则：英文正本，中文镜像。** 按产物被否决。作者用中文叙述，而播客从中文开始，所以
  那份被镜像出来的稿子才是被录下来的那一份 —— 意味着那件被录制的产物，会是一份写来被用某种语言
  念出来、而没人打算用那种语言去念它的文档的译本。

- **只对这一类反转规则：中文正本，英文镜像。** 被否决，因为它什么都没修，它只是把伤害挪到了另一种
  语言上。那样英文那一集就会是中文语流的一份译本，而这个仓库的默认受众读英文。

- **把中文稿放进 `docs/zh/walkthrough/`，并给 `build-index.py` 加一条例外。** 否决。那意味着去改
  一个当前守着 191 条记录的生成器，好让一个特例去抵消掉那个目录本身正在发出的一个信号。更便宜的
  修复是不发出那个信号。

- **一份稿子，一种语言，没有第二个版本。** 作为一个伪装成简化的决定而被否决。这个仓库已经带着一份
  中文镜像，因为那份受众是真实的；为了唯一一种为**被听**而作的格式 —— 这里最可及的那种格式 ——
  把它砍掉，会是省错了地方。

## 后果

- **`docs/index.json` 在过去只多一条记录加一份镜像的地方，现在多一对完整记录。** 两份稿子都算作
  文档。那个镜像覆盖率徽章不动，而且不该动：什么都没有被镜像。
- **这两份稿子会分岔，而那是被允许的。** 同样的拍、同样的源、同样的顺序，不同的笑点和不同的句长。
  **不**被允许的，是一份里有一个事实、而它在另一份的 `sources:` 里不存在 —— 而那正是那份共享
  源清单存在去让它可核查的东西。
- **viewer 需要一个新的能力，而它第一次发布时没带。** 导航里的一切以前要么是英文正本、要么是一份
  `derived` 的中文镜像，而这两份稿子都是正本 —— 所以第一次构建之后，一位英文读者在侧边栏里拿到了
  一个中文标题，而在英文稿上拿到了一条写着*还没有中文镜像*的元信息栏，那纯粹是假的。修复是三小块：
  `docs/build-index.py` 在 front matter 声明时记录一份文档自己的 `language:` 和它的
  `counterpart:`；导航列出用屏幕上那种语言写的那一份 —— 就是它已经对那 26 份镜像所做的隐藏，
  套用到一个同侪而不是一个派生物上 —— 而那条元信息栏提供 `🌐 中文` / `🌐 English`，用你要去的那种
  语言标注，并且绝不把它叫成一份镜像。
- **那个预测就写在这份 ADR 里，而它照样带着毛病发布了。** 被这一段取代的那一段说过，viewer 会需要
  一个不同的能力。把那件事写下来并没有把它建出来，而且没有任何机械的东西能抓住它：这个仓库里没有
  哪个 `--check` 知道一条侧边栏对一位读者来说长什么样。那和
  [ADR-0008](0008-a-count-is-not-a-bound.md) 关于一条只住在散文里的界限所不得不做出的，是同一份
  承认。
- **这是对那条语言规则的一次收窄，不是一次废除。** 这个仓库里其他每一份文档都不受影响：英文仍然是
  事实来源，`docs/zh/` 仍然是一份镜像，而那个徽章仍然说它落后多少。变的是这条规则现在说清了它当初
  在做它那两份工作中的哪一份。
