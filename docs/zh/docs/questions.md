> 这里其余的一切记录的是这个仓库**知道**什么。这一份记录的是它**被问过**什么 —— 包括那些它决定
> 不去回答的问题，以及为什么。

**当有人想知道、而这个仓库说不出来的那一刻**，一个问题就挣到了一行。它保住那一行，直到三件事之一
发生：一个答案被写出来并被链接、这个问题被判定在范围之外并附上理由，或者结果发现它早就被回答过、
只是没人找得到 —— 而那是一条关于索引的发现，不是一条关于这个问题的发现。

**这不是 [`interview/`](../cross-cutting/interview/README.md)。** 那些是*别人问你*的问题，配上
每一个所探的东西。这些是*你问这个仓库*的问题。方向是相反的，受众也是。

一个指向早已在做这件事的地方的指针。

**当有人想知道、而这个仓库说不出来的那一刻**，一个问题就挣到了这里的一行。上面那张表不会一直空着。

## 边界

四个问题到来时，想要的是这个仓库已经决定不去做的东西。**没有一个被拒绝。** 每一个都被收窄到那个
不打破规则的版本 —— 而在这四个里，那个版本同时也是更有用的那个，这件事值得注意，而不该被当成一份
安慰。

记在这里，好让那次收窄不必被重新发现一遍。*一个被答了一半、而没有记录哪一半被剪掉的问题，会被
完整地再问一遍。*

| 被问到的 | 保留了什么 | 剪掉了什么，以及为什么 |
|---|---|---|
| **我该买哪台防火墙？**（#4） | 你在一个给定环境里会*看到*什么，以及它取代了什么。 | 一份采购推荐。[ADR-0002](adr/0002-the-reference-office-is-parameters-not-a-bill-of-materials.md) 只允许型号名出现在一个带日期的 `Reference build` 里，而它的进入条件是某个 build-out 步骤需要一个 —— 而没有一步需要。*"Palo Alto 取代了什么？"*是历史、可迁移；*"买 Palo Alto"*是一个两年前的意见。 |
| **一份排障命令参考**（#10） | 验证调试梯子每一级的那条命令。 | 一份命令参考。那一章明说的高度是*某个人必须做出并担起来的那些决定* —— 它训练的是跑一个网络，不是读线上的东西。一条逐级的命令服务于那架梯子；一份参考会用"回忆"取代它。 |
| **AWS、GCP 和 Oracle Cloud 各自怎么设计他们的网络服务？**（[platforms #1](questions/platforms.md)） | 每个平台自己的网络设计，在它已经住着的地方 —— 以及那份横跨七个平台的逐层对比，在它已经住着的地方。 | 第四份对比三朵云网络的文档。[`the-stack/02`](../the-stack/02-network.md) **就是**这个仓库横跨平台对比某一层的那个地方；一份三方笔记会在 `mixed` 的立足点上把它重述一遍，而重述一条 ramp 并不会让它变深。那次收窄是：这个问题早就被回答过两次，需要的是一个指针，不是一个页面。 |

## 往这个文件里加东西

**一个问题进来，是在你想知道而这个仓库说不出来的时候** —— 不是在"能覆盖一下会很好"的时候。差别
在于到底有没有人真的问过。

当一个问题被回答时，改状态并链上那个答案；不要删掉那一行。这个仓库不知道什么的清单，比它覆盖了
什么的清单更有意思，而且它是那段历史唯一活下来的地方。

**那次拆分已经发生了。** 明说的阈值是第三个域出现，或者单个域超过二十五个问题；七个域一次到齐，
而第一个条件被越过了四个。这一页现在是那个索引，而每一个域是 [`questions/`](questions/) 下面的
一个文件。

**下一条阈值，因为一条已经触发过的规则需要被替换而不是被删掉。** 一个域文件超过**二十五个问题**
时，按同样的方式拆成子域。而一个问题**全部**被回答掉的域不会被删掉 —— 它留着，因为这个仓库不知道
什么的清单，是别处哪儿都活不下来的那部分。
