## 瓦片源

`tiles.tiles` 是一份色板，后面跟着每个瓦片一个十六乘十六的块，一个字符一个像素地画出来。它是那个
源；那个 PNG 是派生的，绝不能手工编辑。

那个构建器刻意是刚性的。一行不是恰好十六个字符，或者出现一个色板没有定义的字符，都是一次
**绘图错误**，而它会失败而不是去补齐 —— 这是它第一次运行时挣到的：它抓住了一行十七个字符，
而那行否则会把一个瓦片挪一个像素，然后没有任何人会注意到。

文本进、位图出，是有意的。一次瓦片改动仍然是一份可评审的 diff，而那个运行时仍然拿到一张它可以每帧
blit 几千次、而不用每次加载都栅格化任何东西的图集。那和
[ADR-0007](../../docs/adr/0007-a-figures-medium-is-decided-by-what-renders-it.md)
为那些 hero 图所做的是同一笔交易。

**一套色板，而且它不跟随读者的主题。** 一个游戏场景有它自己的光，而遵从那个主题开关会意味着两张
手绘图集，外加一个没人写过的守卫
（[ADR-0013](../../docs/adr/0013-godot-is-a-design-tool-and-the-floor-keeps-one-palette.md)）。

有三条规则决定什么能进这张图集，而这张图集的第一版三条全破了：

- **渐变要移色相，绝不只是压暗。** 木头往阴影里走偏红、往光里走偏黄；显示器外壳往阴影里走偏蓝。
  一条靠压低同一个色相亮度做出来的渐变，读起来像塑料。
- **明度按层分级，而地板是最暗的那块大面积。** 地毯最低，家具居中，人在局部对比上最高，好让一个人
  在一张桌子前读得出来、一张桌子在地毯上读得出来。第一张图集有一块中偏亮的地毯、接近白的墙，
  以及比两者都亮的木头 —— 一切都在打架，而墙赢了。
- **瓦片是按边缘优先设计的。** 一堵墙是格子**里面**的一条带，不是那个格子。把格子填满，会让两间屋子
  相接的地方那道隔断读起来有四个瓦片那么厚，因为每间屋子都画了自己的外周；那条带让两间屋子共享一堵
  看得见的墙。

**那个投影是 45 度 —— 正面加一点俯视，不是等距。** 你看到的是一台显示器的正面和一个抽屉的正面。
任何纯俯视画出来的东西（第一把椅子就是）都会和它周围的一切格格不入。

## 什么是从图集里画的，什么不是

| 来自 `tiles.tiles` | 在代码里画 |
| --- | --- |
| 地毯、墙、窗、门、桌子、椅子、会议桌、电话亭、机柜、植物、打印机、柜子、电梯厅的家具 | 它们各自落在哪个格子里 |
| | 那群**人**，从一小组零件生成，因为六十五个人形需要变化，而没有人打算画六十五遍 |
| | 接入点、网段色块、覆盖渐变、那些图例 |

**一个 pod 是一张长桌。** 两排桌子背靠背拼起来，人坐在外侧，隔着一条显示器脊柱面对面 —— 而那就是
一层开放式办公楼面的样子。第一个版本是一排桌子和一排人交替，而那不是任何办公室会有的布局。这也是
为什么有两个桌子瓦片和两个椅子瓦片：长桌远侧露出的是它那些显示器的背面，而一把椅子的靠背在坐着的
人**不**面向的那一侧。

每一次精灵调用都有一个扁平回退。如果那张图集加载失败，楼面照样画得出来，而那个论证照样站得住 ——
一件缺失的装饰不该把材料一起带下去。

## Godot 证明这个楼面；它不画这个楼面

[ADR-0013](../../docs/adr/0013-godot-is-a-design-tool-and-the-floor-keeps-one-palette.md)
定下了 Godot 是设计期的、而且**永远**不交付到浏览器。那仍然成立。变的是它**用来干什么**。

```bash
python3 tools/floor/prove-topology.py            # 走一遍这层楼，报告
python3 tools/floor/prove-topology.py --stamp    # 走一遍，然后把结论记下来
python3 tools/floor/prove-topology.py --check    # 给 CI 用：这块 plate 还被证明着吗
```

那块 plate 是手工创作的 JSON，而且保持这样。在无头 GDScript 里生成一份布局，只是用一种评审起来更差
的语言写同样那些坐标 —— 恰好就是 ADR-0013 对 `.tscn` 提出的那个反对意见。Godot 做的是另一件事，
一件没法被断言的事：

**它走这层楼。** [`godot/prove_topology.gd`](../../../../tools/floor/godot/prove_topology.gd)
从电梯厅出发、只沿动线泛洪，并报告任何它到不了的屋子或空间，以及任何它必须穿过的工位格。它第一次
运行就失败了，而它失败得对：电梯厅的门开在 x=5，而走廊环从 x=8 开始；大屋子的门开在 x=40，而那个
环在 x=37 结束。**两扇开向虚空的门，在一张看起来没问题的图上。** 两扇都熬不过那次证明，而两扇都不会
被眼睛抓到。

`--stamp` 记录日期、结论，以及那块 plate **几何**的指纹 —— 那些矩形、那些门、那条动线、那些工位组，
别的都不记，所以给一间屋子改名不会让一次证明失效，而挪一堵墙会。`--check` 比对那个指纹，而这正是
为什么**一份没有 Godot 的克隆不会卡住**：它跳过那次行走，仍然抓得住一块自有人证明过之后就挪动过的
plate，然后以 0 退出。那份"读者什么都不用装"的承诺是对读者的承诺；一个要挪一堵墙的贡献者要装
Godot。

**它刻意不检查什么：** 走廊宽度、疏散距离、到出口的行走距离、卫生设施配置。那些是建筑学，而
[ADR-0014](../../docs/adr/0014-the-plate-stops-at-topology.md) 就是那条线被论证的地方。
